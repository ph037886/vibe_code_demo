EXPECTATION AND VARIANCE · CLASSROOM EXPERIMENT

A / B Card Lab

Two cards. One discarded outcome. Would you choose A or B?

Rules and classroom setup

This is a classroom adaptation inspired by a card probability puzzle discussed in LIAR GAME. It does not claim to reproduce a verified manga chapter.

  1. Card 1 has a Joker face and a back. Card 2 has two backs.
  2. Choose a card uniformly, then choose its visible side uniformly.
  3. If the first side is a Joker, discard this draw. Nobody scores.
  4. If the first side is a back, reveal the other side. Joker: A scores. Back: B scores.
  5. Replace the card and randomize again after every draw, including discarded draws.

Use two equal-size, opaque handmade cards in a bag for a physical version. Both cards must be equally likely and either side must be equally likely to appear first. This page simulates those assumptions.

P(A scores | valid) = (1/4)/(3/4) = 1/3

Define X = +1 for A and −1 for B, per valid round.

E[X] = −1/3   ·   E[X²] = 1   ·   Var(X) = 8/9

For n independent valid rounds, Sₙ = X₁ + … + Xₙ. E[Sₙ] = −n/3 and Var(Sₙ) = 8n/9. For the average score, Var(Sₙ/n) = 8/(9n).

Per raw draw, Z takes +1, 0, −1 with probabilities 1/4, 1/4, 1/2. E[Z] = −1/4 and Var(Z) = 11/16. These describe a different random variable.

A fair payment rule

Let Y = 1 when A scores and 0 when B scores. A receives +2 tokens for a win and pays 1 token for a loss.

W = 3Y − 1   ·   E[W] = 0   ·   Var(W) = 2

Fair expected payment still allows variable outcomes. Tokens are hypothetical classroom points.
